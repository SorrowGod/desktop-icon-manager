# 安装包说明

当前项目使用 Inno Setup 生成 Windows 安装包。

## 当前状态

本机已安装 Inno Setup 编译器 `ISCC.exe` 到当前用户目录：

```text
%LocalAppData%\Programs\Inno Setup 6\ISCC.exe
```

已经生成安装包：

```text
dist\DesktopIconManagerSetup-1.0.0-x64.exe
```

安装向导文本已在 `installer\DesktopIconManager.iss` 中内置简体中文覆盖，包括欢迎页、安装位置、附加任务、准备安装、安装中、完成页和常用按钮。

同时保留：

- 安装脚本：`installer\DesktopIconManager.iss`
- 编译脚本：`installer\build-installer.ps1`
- 最新发布版目录：`publish\win-x64-manager-ui-fluent`
- 便携版可压缩交付

## 安装包行为

安装包设计为当前用户安装，不需要管理员权限：

- 默认安装目录：`%LocalAppData%\Programs\DesktopIconManager`
- 可选创建桌面快捷方式
- 开始菜单包含“桌面图标整理”“使用说明”“卸载”
- 卸载时删除程序文件和自动整理启动快捷方式
- 卸载时不删除 `%AppData%\DesktopIconManager` 中的方案、快照和日志，避免误删用户数据

## 如何生成安装包

在项目根目录运行：

```powershell
.\installer\build-installer.ps1
```

安装包会输出到：

```text
dist\DesktopIconManagerSetup-1.0.0-x64.exe
```

## 如果只交付便携版

可以直接交付：

```text
publish\win-x64-manager-ui-fluent\DesktopIconManager.exe
publish\win-x64-manager-ui-fluent\使用说明.txt
```

也可以交付压缩包：

```text
dist\DesktopIconManagerPortable-1.0.0-x64.zip
```

如果需要包含高 DPI 弹窗修复的最新版便携包，请使用：

```text
dist\DesktopIconManagerPortable-1.0.0-x64-dpi-fix.zip
```

## 给别人使用时发哪些文件

推荐只发安装包：

```text
dist\DesktopIconManagerSetup-1.0.0-x64.exe
```

对方双击安装即可。安装包内已包含程序本体和使用说明。

如果不想安装，可以发便携版：

```text
dist\DesktopIconManagerPortable-1.0.0-x64.zip
```

高 DPI 弹窗修复后的便携版：

```text
dist\DesktopIconManagerPortable-1.0.0-x64-dpi-fix.zip
```

对方解压后双击 `DesktopIconManager.exe` 即可。

一般不需要把源码、`publish` 文件夹、`installer` 文件夹或 `README.md` 一起发给普通用户。
