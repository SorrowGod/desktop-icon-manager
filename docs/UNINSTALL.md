# 卸载说明

## 从开始菜单卸载

安装版会在开始菜单创建“卸载 桌面图标整理”入口。点击后按向导完成卸载即可。

## 卸载会删除什么

卸载程序会删除：

- 程序安装目录中的 exe 和说明文件。
- 开始菜单快捷方式。
- 安装时创建的桌面快捷方式。
- 当前用户启动文件夹中的自动整理快捷方式。

## 卸载不会删除什么

卸载程序不会删除 `%AppData%\DesktopIconManager` 中的用户数据，包括：

- 方案配置。
- 布局快照。
- 文件收纳撤销记录。
- 日志和诊断包。

这样做是为了避免误删恢复记录。若你确定不再需要这些数据，可以手动删除 `%AppData%\DesktopIconManager` 文件夹。

## 真实桌面文件

卸载不会删除、移动或重命名你的桌面真实文件。
