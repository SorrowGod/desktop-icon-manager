# 桌面管理器使用说明

适用版本：`1.1.5`

这份说明会随着软件版本更新。当前版本优化了“应用布局”生效校验：如果某些电脑因为桌面开启“自动排列图标”导致点击应用后图标不动，软件会尝试关闭自动排列后再摆放，并在应用后重新读取真实坐标确认是否到位。

## 1. 软件会不会动我的文件

普通整理功能只修改 Windows 桌面图标的显示坐标。

它不会：

- 删除文件
- 移动真实文件
- 重命名文件
- 修改文件内容
- 修改普通文件图标

点击“预览”也不会移动桌面图标。只有点击“应用”，并在确认弹窗里再次确认后，才会修改桌面图标位置。

如果 Windows 桌面右键 `查看` 中开启了 `自动排列图标`，Windows 会接管图标位置，导致自定义坐标不生效。1.1.5 开始，软件在应用布局时会尝试关闭这个桌面视图选项，然后再摆放图标。

## 2. 打开软件

安装版：

- 桌面快捷方式名称通常是 `桌面图标整理`。
- 安装后程序通常位于 `%LocalAppData%\Programs\DesktopIconManager\DesktopIconManager.exe`。
- 开始菜单中也会有 `桌面图标整理`、`使用说明`、`更新日志`、`隐私说明` 和卸载入口。

便携版：

- 解压 `DesktopIconManagerPortable-版本号-x64.zip`。
- 双击解压目录里的 `DesktopIconManager.exe`。
- 不需要安装，复制到其他 Windows 10/11 x64 电脑也可以使用。

本机测试版：

- 如果是在当前开发电脑上测试，我会把桌面快捷方式重新绑定到最新发布目录。
- 当前 1.1.5 测试版发布目录是 `D:\test\DesktopIconManager\publish_1.1.5\win-x64-manager-ui-fluent\DesktopIconManager.exe`。

如果双击打不开，可以右键桌面快捷方式，查看“目标”是否指向存在的 `DesktopIconManager.exe`。

## 3. 推荐的基本使用流程

1. 打开软件。
2. 进入“整理布局”页面。
3. 选择目标屏幕。
4. 选择布局方式，例如“左边”“右边”“上面”“下面”“中间一团”。
5. 选择排序方式，推荐默认“类型分组”。
6. 点击“预览”，先看整理后的点位。
7. 如有不想移动的图标，进入“图标管理”页面勾选“保持原位”。
8. 确认预览没问题后，点击底部“应用”。
9. 在确认弹窗里再次确认后，软件才会整理桌面图标。
10. 应用后软件会重新读取真实桌面坐标；如果没有到位，会弹出“应用后未完全生效”提示。

## 4. 整理布局页面

可选布局：

- 左边：先排满第一列，从上到下，再排第二列。
- 右边：先排满右侧第一列，从上到下，再向左排第二列。
- 上面：先排满第一行，从左到右，再排第二行。
- 下面：先排满底部第一行，从左到右，再向上排第二行。
- 中间一团：根据图标数量生成紧凑网格，整体居中。
- 自定义图案：把图标摆成圆形、心形、星形、文字等图案。
- 桌面分区：按桌面区域分别摆放不同类型的图标。

排序方式：

- 类型分组：推荐默认方式。先按文件夹、快捷方式、文档、图片、音视频、压缩包、系统图标、其他分组，再按名称排序。
- 名称 A-Z：只按名称排序。
- 保持当前顺序：只改变摆放位置，不改变当前读取到的相对顺序。
- 最近修改时间：适合按新旧文件整理。
- 文件大小：适合查找大文件。
- 扩展名：适合按文件后缀整理。

## 5. 自定义图案

进入“整理布局”页面，把“布局”切换为“自定义图案”。

可以选择：

- 圆形
- 半圆
- 心形
- 星形
- 波浪线
- 斜线
- 方阵
- 环形
- V 字形
- X 字形
- 文字轮廓
- 图片蒙版
- 手动点位

常用设置：

- 图案：选择图案类型。
- 填充：选择图标填入图案的顺序。
- 文字：选择“文字轮廓”时填写，例如 `WORK`、`学习`、`2026`。
- 图片路径：选择“图片蒙版”时使用，软件只读取图片深色区域来计算点位，不会修改壁纸。
- 中心 X / 中心 Y：控制图案在桌面上的位置。
- 宽度 / 高度：控制图案大小。
- 旋转：控制图案角度。
- 间距：控制图标点位密度。

1.1.1 版本开始，自定义图案预览会按真实桌面图标网格生成点位。这样点击“应用”后，Windows Explorer 把图标吸附到网格时，实际位置会更接近预览。

需要注意：

- 如果 Windows 桌面右键菜单里的“查看 -> 自动排列图标”被打开，系统可能会接管图标位置，导致自定义图案被打乱。
- “将图标与网格对齐”开启时，图标会被吸附到桌面网格，这是 Windows 的正常行为；当前版本的预览已经按这个网格计算。
- 更换显示器、分辨率、缩放比例后，建议重新点击“预览”，确认位置后再应用。
- 图标数量较少时，复杂图案会只显示关键轮廓；图标数量较多时，多余图标会补充到图案附近的紧凑网格。

手动点位：

1. 先把桌面图标手动摆成你想要的图案。
2. 打开软件。
3. 进入“整理布局”页面。
4. 在自定义图案区域点击“记录当前点位”。
5. 软件会把当前桌面图标位置记录成一组手动点位。
6. 以后选择“手动点位”并点击“应用”，就可以恢复成这个图案。

“记录当前点位”适合这种情况：你已经手动摆好了一个好看的图案，想让软件记住它。它记录的是桌面图标当前坐标，不会记录或修改文件内容。

## 6. 桌面分区

桌面分区不会创建真实文件夹，也不会移动真实文件。它只是一组图标坐标规则。

默认分区包含：

- 常用软件
- 工作文件
- 媒体与压缩包
- 待处理

每个分区可以设置：

- 名称
- 位置
- 大小
- 分区内部布局
- 分区内部排序
- 匹配的文件类型
- 匹配的名称关键字

使用方式：

1. 进入“桌面分区”页面。
2. 新建、编辑或恢复默认分区。
3. 回到“整理布局”页面。
4. 把布局切换为“桌面分区”。
5. 点击“预览”查看分区边界和图标目标位置。
6. 确认后点击“应用”。

分区规则：

- 默认内置分区不能删除，包括 `常用软件`、`工作文件`、`媒体与压缩包`、`待处理`。
- 内置分区可以编辑匹配类型、名称关键字、布局和排序。
- 新增或删除自定义分区后，软件会自动重新排布所有分区的位置和大小，减少重叠。
- “恢复默认分区”会回到软件推荐的四个默认分区。

## 7. 图标管理

进入“图标管理”页面，可以：

- 搜索图标名称。
- 按类型筛选。
- 勾选某些图标“保持原位”。
- 批量排除系统图标。
- 全选排除、清空排除、反选。

被勾选为“保持原位”的图标不会参与整理，也不会被移动。

排除项、布局、排序、分区、场景、开机自启动、更新检查等设置会在你更改时自动保存。底部“应用”按钮只用于真正整理桌面图标，不再要求为了保存开关而额外整理一次桌面。

如果某次点击“应用”后桌面看起来完全没变，先检查桌面右键 `查看 -> 自动排列图标` 是否开启。1.1.5 会尽量自动关闭它，但有些系统策略或安全软件仍可能阻止这个设置变化。

## 8. 快照恢复和撤销

软件每次应用整理前，都会自动保存当前桌面布局快照。

可用操作：

- 保存当前布局：手动保存当前桌面点位。
- 恢复所选快照：恢复到某一次历史布局。
- 恢复：如果没有选中快照，默认恢复最近一次快照。
- 撤销上次整理：恢复到最近一次应用前的布局。

恢复快照前，软件也会先保存当前布局，方便反悔。

## 9. 场景模式

内置场景：

- 工作模式
- 学习模式
- 游戏模式
- 演示模式
- 极简模式

这些内置场景不能删除。即使误删，软件下次启动也会自动恢复。

你自己保存的新场景可以删除。

场景只会把布局、排序、分区和排除设置套用到当前方案，不会立即移动桌面图标。真正整理仍然需要点击底部“应用”，并在确认弹窗中确认。

1.1.3 开始，场景模式页面下方会直接显示当前场景设置：

- 默认布局
- 默认排序
- 是否使用桌面分区布局
- 是否排除系统图标

修改后点击 `保存场景设置`，会保存到当前选中的场景。内置场景也可以这样修改，但仍然不能删除。

如果你已经在其他页面把当前方案调好了，例如设置好了自定义图案、排除项或桌面分区，可以点击 `用当前方案更新场景`，把当前方案的完整规则保存到当前场景。

## 10. 方案中心

方案用于保存一整套整理规则。

支持：

- 直接编辑方案核心设置
- 保存方案设置
- 设为默认方案
- 新建
- 复制
- 重命名
- 删除
- 导入
- 导出

导出后的方案可以复制到其他电脑导入使用。不同电脑屏幕尺寸不一样时，分区和图案会按比例适配。

方案中心页面左侧显示所有方案，右侧显示当前选中方案的编辑区。可以直接修改：

- 布局方式
- 排序方式
- 目标屏幕
- 快照保留数量
- 是否使用 Windows 当前图标间距
- 是否开启安全整理
- 是否开机自动整理
- 是否排除系统图标

修改后点击 `保存方案设置` 才会写入该方案。复杂内容仍然在对应页面编辑：

- `编辑桌面分区`：跳到桌面分区页面。
- `编辑自定义图案`：跳到整理布局页面。
- `编辑排除图标`：跳到图标管理页面。

方案只保存软件规则，不会删除、移动或重命名桌面文件。

## 11. 设置与诊断

开机自动整理：

- 默认关闭。
- 开启后，会在当前用户启动文件夹创建“自动整理快捷方式”。
- 不写系统级注册表。
- 不需要管理员权限。
- 自动整理模式不会弹确认框，完成后自动退出。
- 这不是桌面快捷方式。桌面快捷方式是你手动打开软件用的；启动文件夹里的快捷方式只用于开机自动整理。
- 开关改动会自动保存并立刻创建或删除启动文件夹快捷方式，不需要点击底部“应用”。

检查更新：

- 可以在“设置与诊断”页面手动检查更新。
- 启动时检查更新默认开启，但只会提示，不会自动下载或自动安装。
- 默认更新清单地址是 `https://sorrowgod.github.io/desktop-icon-manager/update.json`。
- 如果默认地址连接失败，1.1.4 起会自动尝试备用地址 `https://raw.githubusercontent.com/SorrowGod/desktop-icon-manager/main/update.json`。
- 如果更新清单地址为空、仍是示例地址或本地 `update-manifest.example.json`，软件会自动切换到正式更新清单地址。
- 如果你手动填写了其他更新清单地址，软件不会强行覆盖。
- 1.1.0 或 1.1.1 的旧电脑如果从未配置过这个地址，可能需要先手动填一次，或直接安装新版。
- 如果提示 SSL/TLS/证书连接失败，说明软件还没读到 update.json。常见原因是系统日期时间不正确、Windows 根证书过旧、代理或杀毒软件拦截 HTTPS、公司/校园网络限制 GitHub。可以先用浏览器打开更新清单地址，再尝试同步系统时间、切换网络或更新 Windows。
- 软件不会静默下载安装包，也不会自动上传任何信息。

诊断功能：

- 打开配置文件夹。
- 打开日志。
- 复制诊断信息。
- 导出诊断包。
- 恢复默认配置。

诊断包默认会脱敏桌面文件路径。如果勾选“包含完整路径”，诊断包可能包含用户名、桌面文件名和文件夹结构。

恢复默认配置只重置软件设置、方案和场景，不会删除快照，也不会影响真实桌面文件。

## 12. 文件收纳

文件收纳是独立功能，不会在普通“应用布局”时触发。

默认收纳目标都在桌面：

- 文档 -> `桌面\文档`
- 图片 -> `桌面\图片`
- 视频/音频 -> `桌面\视频音频`
- 压缩包/安装包 -> `桌面\压缩包安装包`
- 其他 -> 默认不勾选

使用方式：

1. 进入“文件收纳”页面。
2. 点击“刷新建议”。
3. 检查建议列表和目标文件夹。
4. 如果只想收纳某一类，例如只收纳图片，可以在“大类”下拉框选择 `图片`，再点击“只勾选此类”。
5. 也可以手动逐项勾选或取消勾选。
6. 点击“执行收纳”。
7. 在二次确认弹窗中确认。

执行后：

- 目标文件夹不存在时会自动创建。
- 遇到目标位置已有同名文件时会跳过，不覆盖。
- 会生成撤销记录。
- 可以点击“撤销上次文件收纳”尝试移回。

撤销边界：

- 只撤销仍存在于目标位置的文件。
- 如果原位置已有同名文件，会跳过，不覆盖。
- 如果目标位置文件已经被你手动移动或删除，会跳过。

## 13. 数据保存位置

方案文件：

`%AppData%\DesktopIconManager\profiles.json`

设置文件：

`%AppData%\DesktopIconManager\settings.json`

快照文件：

`%AppData%\DesktopIconManager\snapshots.json`

文件收纳记录：

`%AppData%\DesktopIconManager\file-organize-operations.json`

未完成整理记录：

`%AppData%\DesktopIconManager\pending-operation.json`

日志文件：

`%AppData%\DesktopIconManager\desktop-icon-manager.log`

## 14. 常见问题

### 双击桌面快捷方式打不开

安装版先确认快捷方式是否指向：

`%LocalAppData%\Programs\DesktopIconManager\DesktopIconManager.exe`

本机测试版先确认快捷方式是否指向当前最新发布目录，例如：

`D:\test\DesktopIconManager\publish_1.1.5\win-x64-manager-ui-fluent\DesktopIconManager.exe`

如果目标文件存在但仍打不开，可以打开日志文件：

`%AppData%\DesktopIconManager\desktop-icon-manager.log`

### 点了预览后桌面没有变化

这是正常的。预览只计算位置并在软件画布里显示，不会移动桌面图标。

### 自定义图案预览和应用后还是不一样

先检查 Windows 桌面右键菜单：

- `查看 -> 自动排列图标` 建议关闭。
- `查看 -> 将图标与网格对齐` 可以开启，1.1.1 已经按真实网格生成预览点位。

如果分辨率、显示器缩放、任务栏位置发生变化，请重新打开软件或点击“刷新”，再重新预览。Windows Explorer 对桌面图标有网格吸附行为，软件会尽量按真实网格计算，但系统设置仍可能影响最终位置。

### 点应用前会不会自动保存

会。每次应用前都会自动保存快照。

### 如果整理过程中程序中断，图标会消失吗

不会。图标对应的真实文件不会消失。软件只改桌面图标坐标，并且安全整理模式会保存中断恢复记录。下次打开软件会提示恢复。

### 普通整理会不会触发文件收纳

不会。普通“应用布局”只改变图标坐标。只有进入“文件收纳”页面、勾选文件并二次确认后，才会移动真实文件。

### 文件收纳会不会覆盖同名文件

不会。目标位置或原位置已有同名项目时，软件会跳过并显示冲突结果。

### 文件收纳建议为什么为空

常见原因：

- 桌面上没有可收纳的真实文件，只有快捷方式、系统图标或文件夹。
- 文件已经位于 `桌面\文档`、`桌面\图片`、`桌面\视频音频`、`桌面\压缩包安装包` 这些分类文件夹中。
- 文件类型暂时不在默认建议范围内。
- “其他”类型默认不自动勾选，需要你手动确认。

分类文件夹本身不会被建议收纳，避免把 `桌面\图片` 之类的文件夹再移动到别处。

## 15. 兼容性

支持：

- Windows 10 x64
- Windows 11 x64

发布版是自包含单文件程序，可以复制到其他 64 位 Windows 电脑运行。
